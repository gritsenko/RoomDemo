# ТЕХНИЧЕСКОЕ ЗАДАНИЕ / ПРОМПТ ДЛЯ AI-АГЕНТА: «ROOM 07 — VITE + TYPESCRIPT + PIXIJS»

## 1. РОЛЬ И ОБЩИЙ КОНТЕКСТ

Ты — Senior Game Developer & Frontend-архитектор, специализирующийся на **PixiJS (v7/v8)**, **TypeScript** и **Vite**.
Твоя задача — с нуля развернуть и реализовать модульный прототип герметичного survival-квеста **«Room 07»** в ретро-пиксельной киберпанк-стилистике.

### Главный сюжетно-геймплейный твист:

1. **Иллюзия выживания:** Игрок считает, что играет в физический симулятор выживания в заклинившей аварийной капсуле (утечки, голод, дефицит энергии, ремонт проводки).
2. **Бытовая смерть как триггер:** Любая ошибка (удар током от замка, токсичный паек из сломанного синтезатора, разгерметизация) приводит к резкой «смерти» персонажа.
3. **Механика циклов (Inception):** После гибели экран искажается артефактами, героиня судорожно просыпается на койке в той же комнате. Окружение накапливает скрытые системные сбои.
4. **Финал:** Взлом гермодвери `[07]` открывает не свободу, а бесконечную цифровую пустоту с hex-дампом памяти сервера. Вся комната была изолированной симуляцией оцифрованного сознания.

## 2. СТЕК ТЕХНОЛОГИЙ И СТРУКТУРА ПРОЕКТА

* **Сборщик:** Vite (шаблон `vanilla-ts`)
* **Рендерер:** PixiJS (`pixi.js`) в режиме `SCALE_MODES.NEAREST` (pixel-perfect без сглаживания)
* **Язык:** TypeScript (строгий режим `strict: true`)
* **Аудио:** Web Audio API (полностью процедурный 8-bit/synth-звук без внешних mp3)
* **Графика:** Единый мастер-атлас `reference.png` (скриншот макета), нарезаемый кодом на субтекстуры.

## 4. ГРАФИЧЕСКИЙ ДВИЖОК И СРЕЗЫ АТЛАСА

### Настройка сцены (`src/core/app.ts`):

* Виртуальное базовое разрешение: **960 × 540** (соотношение 16:9).
* Принудительное центрирование и сохранение соотношения сторон (Letterboxing) при ресайзе окна.
* Отключение фильтрации текстур:

```typescript
  import { Application, BaseTexture, SCALE_MODES } from 'pixi.js';

  BaseTexture.defaultOptions.scaleMode = SCALE_MODES.NEAREST;
  

```

### Нарезка атласа (`src/atlas/textureSlicer.ts`):

Загружается скриншот `reference.png`. Из него извлекаются `PIXI.Texture`:

1. `roomTexture`: Окно жилого бокса (дверь `[07]`, героиня, синтезатор, койка).
2. `portraitTexture`: Портрет героини в шлеме (нижний левый угол).
3. `biometricsTexture`: Цифровые индикаторы `HP: 48` и `Energy: 96`.
4. `cardFrameTexture`: Оранжевые ячейки слотов под карты.
5. `dpadTexture`: Центральный селектор действий (ромб).
6. `backpackTexture`: Правый слот инвентаря.

*Graceful Degradation:* Если картинка не найдена или не загрузилась, модуль создает цветные процедурные плашки через `PIXI.Graphics`, чтобы прототип всегда запускался без ошибок.

## 5. ИНТЕРАКТИВНЫЕ ХОТСПОТЫ И МЕХАНИКА «СМЕРТЬ — ПЕРЕЗАГРУЗКА»

### Хотспоты комнаты (`src/scenes/roomScene.ts`):

1. **Гермодверь [07]:**
* **Осмотр:** *«Замок обесточен и заклинил. Оголенный шлейф искрит под напряжением.»*
* **Использовать Мультитул:** Удар током. Мгновенная гибель (-100 HP).
* **Использовать Изоленту + Мультитул:** Провода изолированы. Замок разблокирован.


2. **Пищевой синтезатор:**
* **Осмотр:** *«Картридж забит токсичным осадком.»*
* **Съесть паек:** Токсический шок. Мгновенная гибель (-100 HP).
* **Очистить мультитулом (-20 энергии):** Выдает съедобный рацион (+40 HP).


3. **Койка:**
* Отдых восстанавливает запас энергии, но форсирует кошмар и сдвигает счетчик итерации.


4. **Вентиляционная решетка:**
* Попытка грубого вскрытия без инструмента приводит к повреждению хладагента и удушью.



### Алгоритм перезагрузки при гибели:

1. Запуск шейдера искажений (`glitchFilter.ts`) на 400 мс.
2. Воспроизведение звука `audio.playGlitchFlatline()`.
3. Fade to black (0.3 с).
4. `state.iteration += 1`, `flags.systemGlitchLevel += 1`.
5. Сброс HP и энергии к начальным значениям.
6. Текст пробуждения:
* *Итерация 1:* «Опять этот кошмар... Воздух кончается, нужно спешить.»
* *Итерация 2:* «Голова раскалывается. Мне кажется, я это уже делала...»
* *Итерация 3:* «Стоп. Этот синтезатор не мог сломаться точно так же...»



### Финал (Итерация 4+):

При открытии двери вместо коридора отрисовывается бесконечная цифровая сетка и терминальный лог:

```text
CRITICAL FAULT: SIMULATION REBOOT FAILED.
NODE_07 CORRUPTED. REALITY CONSTRUCT DISCONNECTED.
CONSCIOUSNESS ID #8849-B DESTABILIZED.

```

## 6. ПРОЦЕДУРНОЕ АУДИО (`src/core/audio.ts`)

Реализация без внешних библиотек через нативный `AudioContext`:

* **UI Click:** Короткий синусоидальный импульс (800 Hz -> 400 Hz за 40 мс).
* **Card Select:** Высокий меандр (1200 Hz, 60 мс).
* **Electric Shock:** Белый шум через `AudioBufferSourceNode` с резким спадом + низкочастотный buzz (50 Hz).
* **Reboot Glitch:** Модулированная пилообразная волна с эффектом замедления частоты.

## 7. ПОШАГОВЫЙ ПЛАН РЕАЛИЗАЦИИ ДЛЯ АГЕНТА

1. **Инициализация:** Создать проект `npm create vite@latest . -- --template vanilla-ts` и установить `pixi.js`.
2. **Каркас рендера:** Настроить `app.ts` с фиксированным внутренним соотношением 16:9 и отключением сглаживания.
3. **Стейт-машина:** Реализовать `GameState` с подпиской на события (`onChange`), чтобы HUD автоматически перерисовывался при изменении HP, энергии или лога.
4. **Атлас:** Написать `textureSlicer.ts`, нарезающий спрайты с референса либо подставляющий цветные хитбоксы.
5. **Сцена комнаты:** Добавить интерактивные зоны с событиями `pointerdown` и `pointerenter`.
6. **Сцена HUD:** Разместить портрет, бары показателей, 3 слота для карт и текстовую панель субтитров.
7. **Игровой цикл:** Собрать последовательность: выбор карты -> клик по двери/синтезатору -> логика урона/гибели -> глитч -> перезапуск итерации.
